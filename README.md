# U-Net and U-Net++ Image Segmentation

## Project Overview
This project implements and compares U-Net and U-Net++ architectures for binary image segmentation using the Oxford-IIIT Pet Dataset.

## Dataset
Oxford-IIIT Pet Dataset, containing pet images and corresponding segmentation masks.

## Models Implemented
- U-Net
- U-Net++

## Technologies Used
- Python
- PyTorch
- NumPy
- Matplotlib
- OpenCV
- Kaggle

## Tasks
- Dataset preprocessing and loading
- Model architecture implementation
- Model training and validation
- Performance evaluation using Dice Score and IoU
- Segmentation visualization

## Notebook
See `UNET and UNET++ Training.ipynb` for the complete implementation.
